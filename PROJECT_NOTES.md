# Assignment Compliance Notes

This project is designed around PS-5 — E-Waste Collection & Recycling Pickup System.

Core requirements covered:
- Role-based registration/login
- Citizen pickup request
- Citizen status tracking
- Admin approval
- Admin agent assignment
- Collection-centre management
- Agent pickup management
- Requested -> Scheduled -> Collected -> Recycled status flow
- Category catalogue
- Reward points per kg
- Admin dashboard
- Total request count
- Recycled weight
- Category-wise breakdown
- Area/address-wise breakdown

Stretch goal covered:
- Citizen reward wallet
- Reward transaction history
